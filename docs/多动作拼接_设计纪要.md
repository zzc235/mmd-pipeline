## 一、问题

多段 VMD 首尾拼接，最初的实现只做到**字节层**：复制记录、帧号加偏移、排序、重写计数。字节是准的（43962 条逐条一致），但**姿态没接上**。

实测（原神摇 0..446 + 活着dj 0..379，gap 6）：

| 项 | 数据 |
|---|---|
| 骨集 | A 52 / B 252 / 并集 259 / 交集 45 |
| A 段缺（B 独有） | 207 根 |
| B 段缺（A 独有） | 7 根（上半身3、左右足D/ひざD/足首D） |
| 交接姿态差 | 45 根共有骨中 **23 根超阈值**，最大 左ひじ **95.9°** |
| 根链位移差 | `グルーブ` **1.557 PMX 单位 = 124.6 mm** |
| 各段根链 | A：`グルーブ` ／ B：`全ての親`、`操作中心` |

## 二、两个被实测改写的认知

### 1. 不是"跳变"，是「端点保持」在静默污染两端

Blender 的 fcurve 对首键之前做**常量外插**。所以：

- B 独有骨在 A 段 → 保持其**首键值**（不是 rest）
- A 独有骨在 B 段 → 保持其**末键值**（不是 rest）

实测 `足D.R`：f440=(0.9828,-0.1835,…) → f453=(0.9855,-0.1682,…) → f600/f800 **完全相同**。
这 6 根 IK 骨带着 A 的末姿态跑完 B 段 380 帧 → 脚 IK 钉死。

**交界处零跳变**（保持值正好接上），**两端被污染**。所以问题不是"闪一下"，是"静静错着"。

### 2. 只在段首补 rest 键会跨段插值

f0=rest → f454=B姿态，中间 450 帧会缓慢漂移，比现状更糟。
要恒定必须**段首+段末两个键**，或只补在**段末**（利用前向常量外插）。

## 三、共识（评审修正后）

| 项 | 结论 |
|---|---|
| 补键 vs 过渡 | 两件事。补键解决数据完整性与语义确定性；跳变只能靠交接区插值 |
| 全局 vs 局部 | 根链世界变换对齐**先于**局部 slerp，否则关节扭曲 |
| 排序依据 | 按**观众敏感度**：根骨瞬移/脚 IK > 躯干大骨 > 手臂头部。不是按角度 |
| 根骨 | 不能写死 `センター`：根链可能是 `全ての親→グルーブ→センター`，也可能缺环，中文模型命名又不同。要比根链**累加世界变换** |
| 轨道 | 所有轨道共用同一条时间轴；**IK 开关表不能丢** |
| slerp | `dot<0` 取反走最短弧、结果归一化、位置 lerp、新键显式线性插值 |
| 边界 | 同名骨 ≠ 同语义骨。字节层只保证"同骨架链式拼接"；跨骨架属 retarget，另一功能 |
| 验收 | 纯二进制黑盒只能靠"看起来没崩"。要**导入后采样世界矩阵**回放校验 |

## 四、已实现（一期，只读，不需要决策）

1. **帧率口径**：默认 24→**30 fps**（VMD 基准）。不重采样改 fps = 变速，833 帧 24fps 播 34.71 s，30fps 播 27.77 s。
   非 30 时 `S3_motion` 报 WARN 并给时长对照。
2. **全轨道解析**：相机 / 灯光 / 阴影 / **IK 开关表**。实测 `爱乐之城`、`和刻晴睡觉`、`和胡桃睡觉` 各带 1 条 IK 记录。
3. **全轨道拼接保留**：四段一起搬且帧号跟随段偏移。零尾段用例输出**字节完全一致**（不改变已有结果，只补回原本会丢的数据）。
4. **dry-run 体检**：`python -m mmdpipe.chainplan a.vmd b.vmd --pmx 模型.pmx`
   输出全轨道占用、骨集差（含骨名）、交接姿态差（error/warn/info）、根链位移差（含 mm）。
   **不写任何文件**。
5. **接进流水线**：`S3_chain` 自动先跑 dry-run，把"未修的问题"以 WARN 形式挂出来，不阻断。

## 五、待决策（需要你拍板）

### 决策 1：补键策略 —— 实测后这个问题基本消解

| 模式 | f100（A 段） | f600（B 段） | 视觉影响 |
|---|---|---|---|
| `none`（现状） | 基准 | 基准 | — |
| `hold` | **与 none 完全相同** | **与 none 完全相同** | **零**，只是把"隐式保持"变成显式键 |
| `rest` | センター 回 rest（≈1 cm）、足D.R ≈2 cm | ひざD.R **≈11 cm**、足首D.R **≈10 cm** | 有可见变化 |

实测结论：**`hold` 与 `none` 逐骨位置完全一致**（f100/f600 全采样相同）。也就是说补键本身不改变任何画面——它只是数据卫生（便于再拼接、Blender 烘焙、跨软件处理）。

同时这也印证了你的判断：**补键不消除跳变**。真正影响观感的是下面两个。

建议：默认 `hold`（免费、无风险、显式化），`rest` 保留为"保真"选项但不当默认——它会让 A 段的 センター 归零、B 段的膝盖/脚踝偏移约 10 cm。

### 决策 2：交接区长度（真正决定观感）

43 根共有骨在交界处最大差 **95.9°**。这个只能靠"把过渡拉长"解决，补键没用。

**自动选切点实测无效。** 在 A 段末 147 帧里搜"与 B 首帧姿态最接近"的切点：

| 切点 | 平均差 | 最大单骨差 |
|---|---|---|
| 446（现用） | 29.5° | 95.9° |
| **435（最优）** | **28.4°** | **93.3°** |

只降 4%。说明这两段舞蹈的手部基本姿态本来就不同，A 段末尾找不到更接近的位置。
结论：切点优化对这对动作没用，别在它上面花时间。

**能调的只有 gap。** 95.9° 摊到 N 帧上的摆动速度：

| gap | 过渡帧数 | 每帧摆动 |
|---|---|---|
| 0 | 1 | 95.9°/帧（瞬跳） |
| 6（原来用的） | 7 | 13.7°/帧 |
| 12 | 13 | 7.4°/帧 |
| **20** | 21 | **4.6°/帧** |
| 30 | 31 | 3.1°/帧 |
| 45 | 46 | 2.1°/帧 |

舞蹈类观感阈值取 **5°/帧**，`chainplan` 会直接算给你：

```
过渡速度：gap 6 → 13.7°/帧（建议 gap ≥ 19，约 5°/帧）
```

需要定：默认 gap 用 20 吗？（代价：总时长 +0.47 s）

### 决策 3：根链对齐

实测 `グルーブ` 在 A 末与 B 首相差 **124.6 mm**，且两段的根链**不是同一根**（A：`グルーブ`；B：`全ての親`+`操作中心`）。

需要定：`match`（把 B 整体平移接上）／`keep`（保留各自走位，接受瞬移）／`blend`（跟混合区一起过渡）。

## 七、社区路线（2026-11-10 实测）

**mmd_tools 自己就能做**，不用在二进制层造轮子。

### 依据
- `BoneConverter`：`mat = matrix_local.to_3x3(); mat[1],mat[2] = mat[2],mat[1]; mat.transposed()` → 印证实测标定 `world = 0.08 × swapYZ(vmd)`。
- `use_nla=True` 时每个 VMD 导入即新建一条 NLA 轨道。
- 导出 VMD 是官方支持的能力，**往返实测无损**（最大逐值误差 0.000000，p99 0.000000；只丢模型里不存在的骨）。
- MMDAgent-EX 文档给出混合语义：REPLACE / ADD / MUL + per-motion blend rate。

### 管线
`导入×2(use_nla) → 条带延伸+blend_in → nla.bake → export_vmd`，产物能直接进流水线（12 阶段全 PASS）。

### 两个 NLA 专属坑
1. **两条轨道都设 REPLACE+HOLD → 上层 HOLD 外插向回覆盖整段 A**（A 段冻成 B 首帧）。修：下层 HOLD、上层 NOTHING。
2. **不做淡化会"冻结再瞬跳"**（f447–452 不动，f453 跳 145.7 mm）。修：把上层条带向前延伸 gap 帧、同步 `action_frame_start/end`，再给 `blend_in`。

### 两条路的实测对比（交接处髋部位移）
| 配置 | gap 内行为 | 与字节拼接 |
|---|---|---|
| 字节拼接 | 每帧 24–48 mm 平滑 | — |
| NLA 无淡化 | f447–452 冻结，f453 瞬跳 145.7 mm | f454 后一致 |
| NLA 有淡化 | f448 淡入，f453 到位 | f454 后 **0.0 mm** 一致 |

### 代价
| 指标 | 字节拼接 | NLA 烘焙 |
|---|---|---|
| 文件 | 4.7 MB | 22 MB |
| 曲线 | 665 | 1722 |
| 导入 | 1.8 s | 15.0 s |

### 重要修正
字节拼接**本来就是连续的**。之前"左ひじ差 95.9°"是两段首尾姿态差，经 7 帧插值后为 13.7°/帧的快速摆动，不是瞬跳。

### 残留差异
f440–446 两路有 30.5 mm 差异：NLA 烘焙走求值后姿态（含 IK），字节拼接走原始曲线插值。疑与 mmd_tools README 所述「Blender IK 与 MMD IK 解算差异」有关。

## 八、安全边界（写死）

- 字节层拼接 = **同骨架链式拼接**。跨骨架需要 retarget，不在本功能范围。
- "无损"承诺只对**原始帧**成立；slerp 生成的新帧是浮点重新序列化，需注意 little-endian、四元数 xyzw 顺序、写入前归一化。
- dry-run 是默认第一步，任何写文件动作都在报告之后。
