## 一、这个项目在做什么

**一句话**：把「PMX 角色模型 + VMD 动作 → 带物理的动画成片」稳定复现，并在每一步能失败的地方设断言。

**刻意不做**：GUI 视窗、IK/FK 手动控制层、场景美术/音乐/运镜自动生成。

**安全约定**：源 PMX/VMD 全程只读，改动落在副本，首尾各算一次 sha256。

交付形态是 Blender 扩展 `mmd_pipeline`（当前 1.3.0），既有面板也有 CLI，两者走同一个 `runner.run()`。

## 四、流水线使用说明

### 4.1 安装 / 重装扩展

```bash
# 打包（单一来源）
python -B build_addon.py
# 产出 dist/mmd_pipeline-1.3.0.zip，只认当前版本那个 zip，不拿 dist 旧包冒充

# 安装到全局（注意 -e 会写用户偏好；S6 验收用的是 --no-prefs + 隔离目录）
blender --command extension install-file -r user_default dist/mmd_pipeline-1.3.0.zip
```

扩展的模块名是 `bl_ext.user_default.mmd_pipeline`，**不是**短名 `mmd_pipeline`；短名 `addon_utils.enable()` 会报 `No module named 'mmd_pipeline'`（实测）。

### 4.2 预检（不开 Blender，几秒）

```bash
python -m mmdpipe.preflight 模型.pmx 动作.vmd --json 报告.json
```

回答：这个模型有没有物理、掩码语义对不对、这个 VMD 套得上吗、产物落在哪。

### 4.3 完整成片

```bash
blender -b -P run_pipeline.py -- \
  --pmx "模型.pmx" --vmd "动作.vmd" \
  --out 输出目录 --frames 360 --fps 30 \
  --preset presets/feiying.json \
  [--probe] [--force]
```

参数共 22 个，唯一声明源在 `mmdpipe/params.py`（面板/CLI/测试/续跑全从它生成，避免四处漂移）。常用几个：

| 参数 | 作用 |
|---|---|
| `--physics-policy report\|welded\|strict` | 只报告 / 静音全焊死 / 再加僵死嫌疑（袖子那类） |
| `--clearance --clearance-margin 0.06` | 初始穿透外移（0.06 ≈ 4.8 mm） |
| `--chain-mode splice\|nla` | 字节硬切 / NLA 淡化+对齐+烘焙（贵但能过渡） |
| `--align auto\|none\|match` | 按测量判定 / 不动 / 强制对齐 |
| `--layout isolated\|legacy` | 新默认：失败不留 final；legacy 是旧平铺行为 |

### 4.4 看结果

```
输出目录/
├── work/<run_id>/       中间产物：frames/s_XXXX.png、scene.blend、preflight.json
├── final/<run_id>/      只有全流程通过才落：result.mp4、contact_sheet.png、camera.json、scene.blend、pipeline_state.json
└── pipeline_state.json  最近一次运行的状态
```

**验收先看 `final/<run_id>/contact_sheet.png`（12 帧 / 4×3 联络表）**；没通过时 `final/` 是空的，产物留在 `work/` 可复查。

### 4.5 多段拼接先 dry-run

```bash
python -m mmdpipe.chainplan a.vmd b.vmd --pmx 模型.pmx --gap 6 --json 计划.json
```

只报不改：全轨道占用、骨集差、交接姿态差、根链位移差。确认再拼。
注意 `chainplan` 给的是**局部量**，不是世界位移——世界位移只能在 Blender 里测（实测同一对动作 chainplan 报 124.6 mm，Blender 实测 `センター` 只有 30.5 mm）。

### 4.6 三个必须先知道的口径

1. **帧率**：VMD 帧号以 30fps 为基准。改 fps 不重采样，只改播放速度（833 帧 @30=27.77s，@24=34.71s 慢 25%）。真要 24fps 得先重采样，那是另一个功能且有损。
2. **相机**：测一次冻结复用，别每次测（刚体求解跨进程分叉）。
3. **物理**：能稳定复现「动作/骨骼/材质/相机/构图/帧数/时长」，裙摆头发褶皱有 0.18% 抖动（肉眼不可辨）。

### 4.7 测试

```bash
python -B -m unittest discover -s tests -t tests -p "test_*.py"   # 纯 Python，952 条
blender -b -P tests_bpy/smoke.py                                   # bpy 层，9 项
```

三环境口径：`默认`（无 PYTHONUTF8）、`UTF-8`（`PYTHONUTF8=1`）、`GBK`（`PYTHONUTF8=0 PYTHONIOENCODING=gbk`）。
