## 0. 一句话：为什么要换轴

旧 S2 的变量轴是 **X**，而 X 的实测峰值 `0.5788 rad < 0.7 rad` ⇒「限位从未被触及」在 X 上**必然成立**，
与驱动足不足无关。那不是限位不合格，是**轴选错了**：下摆的运动主要不在 X 上。
`D-170`（Human「换限轴」）因此要求按三轴峰值重选变量轴——本文件把这件事写成可复核的表。

## 3. 判据（1 mm，量化到仪器分辨率，同笔输出 raw float）

### 3.1 仪器分辨率与量化

- 位姿 dump 的坐标已 `round(…, 6)` ⇒ 分辨率 **1e-6 m = 1 µm**，比 1 mm 判据细 1000 倍。
- **量化规则（写死）**：先把每帧每骨的三轴坐标各 `round(…, 6)`，再算欧氏距离
  `Δ_q = ‖pos_臂(骨,帧) − pos_A(骨,帧)‖`；判据用 `Δ_q`。
- **同笔输出 raw float**：同一条记录里再写一次不量化的 `Δ_r`（`D-143`：两个数必须同笔落盘，
  不许「这一版只印量化值、下一版只印 raw」）。

### 3.2 判「有差 / 无差」

| 条件 | 判词 |
|---|---|
| `Δ_q ≥ 0.001000 m` | **有差**（效应量 > 1 mm） |
| `0.000999 ≤ Δ_q < 0.001001 m` 且跨 1 mm 线 | **`BOUNDARY`**：两个数都写，**不判通过** |
| `Δ_q < 0.000999 m` | **无差**（效应量 ≤ 1 mm） |

- 报告必须给：`max Δ_q`、出现帧、骨、`max Δ_r`、以及 `Δ_q > 0.001 m` 的刚体数。
- **1 mm 来自既有验收口径**（早于本文件），不是这次挑的；改它要另出预注册。

### 3.3 判「触及 / 部分触及 / 未触及」（换轴后必须重定义）

v3 的 `0.7 / 0.5 rad` 是**绝对值**，因为当时限值固定为 0.7。本次每臂的限值各不相同，
绝对阈值不再可比，故改成**相对该臂自己限值的比例**（与 v3 用的 0.5 这个数同源）：

| 判定 | 条件（`L` = 该臂 `limit_ang_y`） |
|---|---|
| 触及（被夹住） | `max \|rot_y\| ≥ 0.98 × L` |
| 部分触及 | `0.5 × L ≤ max \|rot_y\| < 0.98 × L` |
| 未触及 | `max \|rot_y\| < 0.5 × L` |

`0.98` 是给解算收敛留的余量；`0.5` 是 v3 就有的那个数。**两者都不是这次挑的新阈值。**

### 3.4 判词（三行，沿用 v3 §3 的形状）

| 触及 + 效应量 > 1 mm | **S2 通过**：写明骨、帧、量级 |
| 触及 + 效应量 ≤ 1 mm | **S2 通过但不重要**：写「限位在该摆幅下不起作用」，M02 不作废 |
| 部分触及 / 未触及 | **`S2 = UNMEASURED`（不是 PASS）**，必须写出 `max \|rot_y\|` 的实际值 |

**「测不出来」永远不等于「没有问题」。** 且 `P12`（1.2×峰值）若给出 > 1 mm 的差 ⇒ **本次作废**（负控失败）。

## 11. 自检仪器的反控记录（这份预注册的数是怎么被核过的）

`m02_check_s2_prereg_v4.py` 对本文件做三层核对：**数值**（这个数在文档里）、**同句**（这个数出现在点了它那根骨的行上）、
**整行指纹**（把一行表格压成指纹，逐行比对）。

**第一版只做了「数值在文档里出现过」这一层，反控立刻暴露它不会红**：把 §2.1 的 `1 744` 手改成 `1 743`，检查器仍然 exit 0
——因为 `1 744` 在 §2 的另一行里也出现过。**「这个数在全文出现过」不是校验，是自我安慰**；
改成整行指纹后，同一处改动立刻红在「整行对不上」。这条记在这里，是为了下一个人别再造一遍同形的检查器。

**同样要记的两条措辞边界**（都是本轮被指出后才改的）：
- 「**峰值相同**」≠「**文件相同**」：六份 dump 三轴峰值逐位相同，其中四份确实逐字节相同、两份不是（§1.4）；
- 「**改了就生效**」≠「**改的值能读回来**」：后者才有证据力（P2 / P5）。
